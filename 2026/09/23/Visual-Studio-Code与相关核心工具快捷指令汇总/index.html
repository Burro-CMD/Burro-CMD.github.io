Visual_Studio_Code与相关核心工具快捷指令汇总

Posted on 2026-09-23 In Tech Views: Word count in article: 1.4k Reading time ≈ 1 mins.
这是一篇VS Code 与相关工具核心快捷键汇总。

1. VS Code 与相关工具核心快捷键汇总

工具 / 场景 快捷键 / 指令 功能说明
VS Code Ctrl + Shift + P 打开命令面板（Search Command Palette）
VS Code Ctrl + ~ 唤起 / 隐藏底部内置终端（Git Bash）
VS Code Ctrl + , 打开 VS Code 设置页面（Settings）
VS Code Ctrl + Shift + X 打开扩展/插件商店（Extensions）
VS Code Ctrl + K 紧接着按 V 在右侧打开 Markdown 实时预览窗口
VS Code Ctrl + Shift + V 打开 Markdown 全屏预览窗口
VS Code Ctrl + 0 重置界面缩放比例为 100%
VS Code Ctrl + - 缩小界面比例
PicGo (插件) Ctrl + Alt + U 从剪贴板上传图片并自动插入 Markdown 代码
PicGo (插件) Ctrl + Alt + E 选择本地文件上传图片
Git Bash / 终端 git status 查看当前 Git 仓库状态与改动
Git Bash / 终端 git pull 拉取 GitHub 远程仓库最新源码
Git Bash / 终端 git add . 添加所有新增/修改的文章及文件到暂存区
Git Bash / 终端 git commit -m "..." 提交更改并添加提交日志
Git Bash / 终端 git push 推送代码到 GitHub（触发 GitHub Actions 部署）
Hexo 本地服务 npx hexo server 或 hexo s 启动 Hexo 本地服务（在 http://localhost:4000 预览）

2. HEXO 博客全流程操作指南（写作、调试、推送）

在 VS Code 内置终端（Ctrl + ~ 打开 Git Bash）中，按照以下步骤依次操作：

阶段一：准备阶段（写作前）

每次开始写新文章前，先拉取 GitHub 上的最新源码：
git pull

阶段二：写作与本地调试

  • 创建新文章（可选，也可以直接在 source/_posts/ 目录下新建 .md 文件）：
    npx hexo new “文章标题”

  • 启动本地 Hexo 实时预览服务：
    npx hexo server
    (快捷命令: hexo s)
    运行后按住 Ctrl 点击终端输出的 http://localhost:4000 即可在浏览器看整站效果。按 Ctrl + C 可停止预览服务。

  • 图片处理：
    使用 PicGo 快捷键 Ctrl + Alt + U 自动上传剪贴板图片并插入 Markdown 链接。

阶段三：提交与推送（自动触发云端部署）

文章写好并测试完毕后，依次执行以下命令推送源码：

  1. 将某一篇新增/修改的文件添加到暂存区：
    git add "source/_posts/Visual-Studio-Code与相关核心工具快捷指令汇总.md"

  2. 将所有新增/修改的文件添加到暂存区：
    git add .

  3. 提交更改，添加日志说明：
    git commit -m "feat: add new post"

  4. 推送到 GitHub 远程仓库（GitHub Actions 会在云端自动编译部署）：
    git push

极简操作复习卡片

日常写博客时，绝大多数时候你只需要按顺序执行这 4 步：

  1. 拉取：git pull
  2. 写作：编辑 Markdown，按 Ctrl + Alt + U 插图
  3. 调试（可选）：npx hexo server 本地预览
  4. 推送：git add . -> git commit -m "..." -> git push
