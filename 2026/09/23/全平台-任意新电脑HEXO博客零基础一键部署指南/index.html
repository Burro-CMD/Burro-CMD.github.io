全平台-任意新电脑HEXO博客零基础一键部署指南

Posted on 2026-09-23 In Blog Views: Word count in article: 1.7k Reading time ≈ 2 mins.
这份指南不仅覆盖了已安装软件的场景，还补充了基础依赖环境安装（Node.js / Git）、PicGo 图床初始化配置、VS Code 云同步配置等全套流程。无论未来是在新买的电脑、实验室电脑还是临时设备上，按此指南操作均可随时完成全新部署。

全平台 / 任意新电脑 HEXO 博客一站式部署指南

部署前准备清单

  • GitHub 账号与密码（用于代码拉取及授权）
  • PicGo 图床密钥/Token（如 GitHub Token 或 SM.MS Token 等）
  • 个人博客源码仓库地址（例：https://github.com/Burro-CMD/burroblog-src-next8.git）

阶段一：基础环境与软件安装（新电脑必做）

在新电脑上首次部署时，需先下载安装以下三款核心基础设施软件：

  1. 安装 Git 与 Git Bash

    • 访问 Git 官网 下载适用于 Windows 的安装包。
    • 双击安装，全程一路点击 Next 保持默认设置即可。
    • 验证安装： 在桌面空白处右键，若出现 Git Bash Here 菜单则表示成功。

  2. 安装 Node.js 运行环境

    • 访问 Node.js 官网 下载 LTS（长期支持版/稳定版）。
    • 按照提示安装完成。
    • 验证安装： 按下 Win + R 输入 cmd 打开终端，运行以下命令： 若能正确打印出版本号（如 v20.x.x），说明 Node.js 已生效。

  3. 安装编辑器与图床软件

    • VS Code： 访问 code.visualstudio.com 下载安装。
    • PicGo 桌面端： 访问 PicGo Release 页面 下载并安装 .exe 客户端。

阶段二：应用配置与云同步还原

  1. VS Code 一键同步配置与插件

    • 打开 VS Code，点击左下角齿轮图标（或账户图标），选择 **Turn on Settings Sync…**。
    • 点击 Sign in & Turn on，登录你常用的 GitHub 或 Microsoft 账号。
    • 自动同步： VS Code 会自动从云端下载安装你的所有插件（PicGo 插件、Markdown 预览插件等）、快捷键配置及个人设置。

  2. 配置 PicGo 客户端与插件路径联动

    • 桌面端配置： 打开安装好的 PicGo 客户端，在“图床设置”中填入你的图床 Token/密钥并设置为默认图床。
    • 检查插件配置文件路径：
      1. 在 VS Code 中按 Ctrl + , 打开设置，搜索 picgo.configPath。
      2. 确认该路径指向新电脑正确的 data.json 文件路径（Windows 系统通常为：C:\Users\你的新电脑用户名\AppData\Roaming\picgo\data.json）。

阶段四：验证与写作流闭环测试

完成上述步骤后，即代表新电脑环境搭建完成，可进行最后的运行测试：

  1. Git 拉取（第一步：同步远程源码）

  2. Hexo 运行（第二步：启动本地预览）

    按住 Ctrl 键点击终端打印的 http://localhost:4000，确认博客界面显示正常，按 Ctrl + C 退出预览。

  3. PicGo 上传（第三步：测试图床插图）

    • 在任意 Markdown 文件中复制一张图片，按下快捷键 Ctrl + Alt + U。
    • 若光标处自动生成图床链接且右下角弹窗提示上传成功，说明新电脑环境已 100% 完美就绪！
