HEXO博客开发环境——已有Git-bash和Picgo

Posted on 2026-09-23 In Blog Views: Word count in article: 1.1k Reading time ≈ 1 mins.
这是一篇介绍home电脑已经安装并配置好了 Git Bash 和 PicGo（且已配置好图床 Token），无需重新一步步手动配置 VS Code 的快捷键和插件路径，只需要通过 VS Code 云同步自动复用设置即可！

第一阶段：安装与配置 VS Code（利用设置同步）

  1. 下载并安装 VS Code
    在home电脑打开浏览器，访问 code.visualstudio.com 下载并安装最新版的 VS Code。

  2. 登录账号开启“设置同步”
    打开 VS Code，点击左下角齿轮图标（或账户图标），选择 **Turn on Settings Sync…**（开启设置同步）。
    点击 Sign in & Turn on，选择你今天在work电脑登录的同一个 GitHub 或 Microsoft 账号。

    • 自动同步： 登录成功后，VS Code 会自动将work电脑上的所有插件（如 PicGo 插件、Markdown 插件）、设置（包含今天填写的 PicGo 路径 C:\Users\...\data.json）和自定义快捷键一键下载并还原！

  3. 校验 PicGo 路径（仅需检查一次）
    在home电脑按 Ctrl + , 打开设置，搜索 picgo.configPath。

    • 注意： 由于home电脑的 Windows 用户名可能与work电脑不同（例如公司是 985hf），请确保该路径指向你home电脑实际的 PicGo data.json 文件位置（通常为 C:\Users\你的家里电脑用户名\AppData\Roaming\picgo\data.json）。
